# Codex Instructions

When creating or updating GitHub pull requests, do not prefix PR titles with
`[codex]` or any other tool attribution. Use a direct, human-readable title
that summarizes the full diff.

PR descriptions should describe what changed, why it changed, and the checks
that were run. Do not add Codex attribution or generated-by wording.

Use semantic commit messages when possible, following the Conventional Commits
format such as `feat:`, `fix:`, `chore:`, `docs:`, or `refactor:`.

## Plan Mode

- Make the plan extremely concise. Sacrifice grammar for the sake of concision.
- At the end of each plan, give me a list of unresolved questions to answer, if any.
